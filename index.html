O Nosso Sensor IoT

Entenda a montagem física e o funcionamento eletrônico do sistema.

Instrumentos Utilizados

  • ESP32: Microcontrolador com Wi-Fi nativo responsável por processar o sinal e enviar ao servidor local.
  • Sensor DHT11 com LED integrado: Coleta os dados do ambiente e possui sinalização visual integrada.
  • Protoboard: Placa de ensaio usada para fixar os pinos dos componentes e criar conexões estáveis.
  • Bateria/Pilha: Fornece alimentação estável para que o módulo funcione sem depender de tomadas fixas.
  • Caixa de Armazenamento com Botão ON: Invólucro robusto protetor com interruptor integrado para ligar/desligar o sistema.
  • 4 Cabos Jumpers & 1 Cabo USB: Jumpers para conexões internas de sinal e energia; cabo USB para programação/alimentação inicial.

Montagem & Funcionamento

Como o hardware do nosso grupo coleta, trata e transmite as medições do Laboratório até a tela do usuário:

1

Coleta de Sinais Físicos

O sensor DHT11 utiliza dois princípios físicos: um termistor NTC (que altera sua resistência elétrica com base na temperatura) e um substrato de retenção de umidade que altera a condutividade elétrica conforme a variação de umidade do ar.

2

Processamento e Filtros

O ESP32 lê os pulsos digitais gerados pelo sensor por meio dos 4 jumpers conectados na protoboard, decodifica a sequência de bits e extrai os valores numéricos exatos de umidade e temperatura.

3

Transmissão de Dados por API

A cada 10 minutos, o ESP32 envia esses dados formatados para o servidor IoT local da escola via protocolo HTTP (método POST) direcionado para os endpoints correspondentes.
